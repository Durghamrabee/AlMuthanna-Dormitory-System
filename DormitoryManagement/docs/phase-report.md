# تقرير تنفيذ النسخة المكتبية — 2026-11-07

## نطاق التنفيذ

أُنشئ التطبيق داخل `DormitoryManagement` مستقلاً عن نسخة Django السابقة. لم يُنقل الطلبة
تلقائياً ولم تُعدّل قاعدة النسخة السابقة أو إعدادات MySQL. نقطة التشغيل الجديدة `main.py`
والاختصار المحلي من المجلد الأب `start-native.cmd`. يبقى `start-local.cmd` للنسخة السابقة.

## أوامر التحقق

نتيجة التحقق عند إنشاء النسخة المكتبية الأولى: **51 اختباراً ناجحاً في 51.06 ثانية**: 25 اختبار قاعدة بيانات وخدمات،
و10 اختبارات Qt للواجهات، و11 اختبار تصدير، و5 اختبارات لفشل التشغيل والتحقق الآلي.
البيئة المنفذة: Python 3.13.17 وSQLite 3.50.4 وQt 6.12.0 وSQLAlchemy 2.0.57.
نجح أيضاً `pip check` وفحص التجميع `compileall`.

بُنيت الحزمة `AlMuthannaNative-Windows-20261107-110404.zip` وفُحصت سلامة ZIP وSHA256
وعدم تضمين قاعدة التشغيل أو ملفات `.env`. شُغّل EXE الناتج فعلياً وانتهى برمز 0:
الشاشات `[0,1,2,3,4,5]`، و19 محافظة و17 كلية، وقاعدة اختبار فارغة دون بيانات طلبة،
وExcel بحجم 5356 بايت وPDF بحجم 15913 بايت. جُرّب مسار بيانات غير صالح أيضاً،
وانتهى برمز 1 ورسالة عربية منظمة دون تعليق أو نافذة خطأ معلقة في وضع التحقق.
أُنشئ اختصار «طلبة الأقسام الداخلية - جامعة المثنى» على سطح المكتب، وفُحص هدفه
ليشير إلى EXE النهائي داخل `DormitoryManagement/dist/AlMuthannaNative`.

من داخل `DormitoryManagement`:

```powershell
.\.venv\Scripts\python.exe -m pytest
.\.venv\Scripts\python.exe -m pip check
.\.venv\Scripts\python.exe -m compileall -q app main.py tools
.\.venv\Scripts\python.exe tools\verify_layout.py
.\.venv\Scripts\python.exe tools\build_windows.py
```

يفحص اختبار EXE الشاشات الست، وتكوين قاعدة فارغة، وإنشاء Excel وPDF فعليين:

```powershell
& '.\dist\AlMuthannaNative\AlMuthannaNative.exe' --smoke-test --data-dir '.\.tools\exe-check' --result '.\.tools\exe-check.json'
```

تُستخدم بيانات اختبار خيالية وقواعد مؤقتة فقط. الإحصائيات في التطبيق لا تُعبأ بأرقام تجريبية.
فُحصت الواجهة على 1366×768 بالحجم الافتراضي و960×700 بتكبير 130%؛ بقيت الصفحات
قابلة للوصول دون تمرير أفقي للصفحة، مع تمرير داخلي للجداول عند الحاجة.
فُحصت صور PDF الفعلية، واتصال الحروف العربية، والمحاذاة، والأرقام الجامعية والأصفار،
والأعمدة المحددة وتقارير أفقية متعددة الصفحات وأسطر طويلة مستمرة.

## حدود البيانات والتشغيل

المراجع تتضمن 19 محافظة و150 قضاء ضمن تغطية جزئية، و17 كلية و35 قسماً/مسمى تسجيل.
لم يثبت اكتمال التقسيم الإداري الحالي، وأقسام ست كليات تحتاج استكمالاً موثقاً من الإدارة.
توضح الاستمارة النقص وتمنع اختيار قسم أو قضاء وهمي. التفاصيل في [مصادر البيانات](reference-sources.md).

جُرّب التطبيق والحزمة في بيئة Windows 11 الحالية؛ لا تُعد هذه التجربة اختباراً مستقلاً على Windows 10.
الحزمة ليست موقّعة بشهادة ناشر تجارية ولا تمثل اعتماداً رسمياً من الجامعة.
التشغيل اليومي محلي بالكامل. الملفات والنسخ الاحتياطية ليست مشفرة وتحتاج حماية حساب Windows.
قواعد النسخة القديمة غير متوافقة للاستعادة المباشرة، وتبقى محفوظة مستقلة.

## تحديث تنسيق التقارير — 2026-11-07

نُفذت اقتراحات تنسيق الملفات السبعة في النسخة المكتبية:

1. عنوان كشف قابل للتعديل مع ترويسة جامعة المثنى.
2. تاريخ إصدار وعدد صفوف فعلي وملخص المرشحات المستخدمة.
3. خط من 8 إلى 16 نقطة واتجاه صفحة اختياري، ومعاينة PDF أصلية قبل الحفظ.
4. ضبط طباعة Excel وعرض الأعمدة وارتفاع الصفوف، وورقة «ملخص التقرير» بعد ورقة الطلبة.
5. ترتيب الأعمدة بالسحب أو الأزرار، وتسلسل اختياري وعبارة «غير مسكن» للسكن غير المخصص.
6. ثلاثة قوالب جاهزة وحفظ وتحديث وحذف القوالب المخصصة محلياً.
7. حقول توقيع فارغة اختيارية واسم ملف مقترح بحسب عنوان التقرير والتاريخ.

الملفات الأساسية: `report_options.py` و`report_profiles.py` و`export_service.py`،
و`reports_page.py` و`report_preview.py` و`main.py`. يغطي التحقق الجديد إعدادات العرض،
خصوصية القوالب، ترتيب الأعمدة والتسلسل، بيانات Excel وخصائص الطباعة، PDF العربي
ومعاينته وحفظ نفس البايتات، والإلغاء وفشل الحفظ وسلامة ملفات حزمة التشغيل.
لم يتغير مخطط قاعدة البيانات في هذا التحديث.

عولج خلل عمر جهاز رسم PDF بفصل مراجع تخطيط النص قبل تحرير الكاتب. كشفت إعادة
الاختبارات أيضاً أن إخفاء نوافذ Qt وحده يترك كائناتها حتى نهاية مفسر Python؛ أصبح
تنظيف شجرة النوافذ صريحاً قبل انتهاء التطبيق، وتستخدم اختبارات الواجهة مالكاً واحداً
لـ`QApplication` مع تنظيف فعلي للنوافذ والموارد المؤجلة.

فُحصت صور PDF فعلية ببيانات خيالية، والمعاينة الأصلية، وواجهات 1366×768 و960×700
مع تكبير 130% دون تمرير أفقي للصفحة. تُختبر إعدادات طباعة Excel برمجياً؛ لم تُجرَ
طباعة ورقية أو مراجعة طباعة داخل Microsoft Excel في هذا التحديث.
يبين [دليل تنسيق التقارير](report-formatting.md) خطوات الاستخدام وحدود القوالب.

## ترتيب واجهة التقارير والتصدير — 2026-11-08
