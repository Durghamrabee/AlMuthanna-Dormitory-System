# تشغيل نسخة Windows الأصلية

## الحزمة الجاهزة

1. فك ضغط ملف `AlMuthannaNative-Windows-....zip` كاملاً إلى مجلد دائم، مثل مجلد البرامج الخاص بك.
2. افتح المجلد `AlMuthannaNative` وشغّل `AlMuthannaNative.exe`.
3. لإنشاء اختصار عربي على سطح المكتب، شغّل `CreateDesktopShortcut.cmd` الموجود بجانب مجلد البرنامج بعد فك الضغط.
4. لا تنقل EXE وحده: مجلد `_internal` يحتوي مكتبات Qt والخط والبيانات المرجعية اللازمة للعمل دون إنترنت.

لا يحتاج المستخدم إلى تثبيت Python أو MySQL أو تشغيل خادم أو متصفح. هذه نسخة Windows x64 أصلية،
وليست نسخة Django التي تُشغّل بواسطة `start-local.cmd`. أبقِ النسخة القديمة محفوظة إذا احتجت الرجوع إليها.

قد يعرض Windows تحذير ناشر لأن الحزمة غير موقعة بشهادة تجارية؛ لم يغيّر البرنامج إعدادات حماية النظام.
لم يُدّعَ اختبار الحزمة على كل أجهزة Windows 10 و11. شغّل الاختبار على جهاز التشغيل الفعلي قبل إدخال البيانات الإدارية.

## أين تُحفظ البيانات؟

```text
%LOCALAPPDATA%\AlMuthannaDormitoryNative\db.sqlite3
```

تُنشأ قاعدة SQLite ومجلد البيانات عند التشغيل الأول. هذا المجلد مستقل عن ملفات EXE وعن مجلد بيانات النسخة القديمة
`AlMuthannaDormitory`. يعمل برنامج واحد فقط على مجلد البيانات نفسه في الوقت ذاته.
لا تُشارك حساب Windows نفسه مع أشخاص غير مخولين إذا كانت عليه بيانات طلبة خاصة.

## التشغيل اليومي والتحديث

افتح الاختصار أو ملف EXE، ثم استخدم القائمة الجانبية. يُحفظ كل تعديل ناجح في قاعدة البيانات مباشرة،
وتتحدث الإحصائيات بعده. أغلق البرنامج بصورة عادية عند انتهاء العمل.
لتحديثه أغلق النسخة الحالية، وفك الحزمة الجديدة إلى مجلد مستقل، ثم أنشئ الاختصار منها.
لا تحذف مجلد AppData. يُنصح بإنشاء نسخة احتياطية قبل التحديث؛ الترحيلات تحفظ البيانات ولا تولد أرقاماً جامعية مزيفة للسجلات القديمة.

## تسجيل الطلبة والمراجع

الرقم الجامعي نص فريد يحافظ على الأصفار الأولى. القوائم مترابطة: القضاء يتبع المحافظة، والقسم يتبع الكلية، والغرفة تتبع البناية.
يمكن حفظ الطالب دون سكن ثم تخصيص غرفة لاحقاً، ويمنع النظام امتلاء الغرفة أو مخالفة جنس البناية.
عند نقل الطالب يعيد النظام فحص المكان داخل معاملة واحدة؛ لا يفقد الغرفة السابقة إذا فشلت العملية.

المراجع المضمنة موثقة لكنها ليست كاملة: تشمل 19 محافظة، و150 قضاء ضمن تغطية جزئية، و17 كلية و35 قسماً/مسمى تسجيل.
أقضية عدة محافظات وأقسام ست كليات تحتاج استكمالاً موثقاً. تُظهر الإعدادات حدود التغطية ويمكن اعتماد المراجع وإضافتها محلياً.
لا تختَر قضاء أو قسماً غير صحيح لمجرد إكمال التسجيل. التفاصيل في `Reference-Sources.md` المرفق بالحزمة.

## التقارير والنسخ الاحتياطي

من التقارير اختر المرشحات والأعمدة ثم Excel أو PDF وحدد موضع الحفظ. يجب اختيار عمود واحد على الأقل.
يضم PDF الخط العربي ويُنشأ محلياً بواسطة Qt، دون Edge أو متصفح. الأرقام الجامعية والهواتف نصوص في Excel.
تتوفر معاينة PDF أصلية وخيارات عنوان وخط واتجاه الصفحة وتسلسل وقوالب وحقول توقيع فارغة؛
راجع `Report-Formatting.md` المرفق بالحزمة. ورقة ملخص Excel تعرض المرشحات والعدد، وتبقى رؤوس ورقة البيانات في الصف الأول.

من الإعدادات أنشئ نسخة احتياطية باستخدام SQLite Backup API واحفظ نسخة إضافية خارج الجهاز إن أمكن.
للاستعادة اختر نسخة موثوقة لهذا البرنامج، واقرأ تأكيد الاستبدال. يتحقق البرنامج من سلامتها وينشئ نسخة أمان من البيانات الحالية أولاً.
قاعدة بيانات Django أو MySQL السابقة ليست بديلاً متوافقاً ولا تُستعاد مباشرة هنا.

## للمطور

ثبّت Python 3.12 أو3.13 x64، وأنشئ `.venv` في مجلد `DormitoryManagement`، وثبّت `requirements-dev.txt`.
افتح `start.cmd` للتشغيل (يفضّل الحزمة داخل `dist` إن وجدت)، أو `build_windows.bat` لبناء EXE.
أثناء التطوير استدعِ `.venv\Scripts\python.exe main.py` مباشرة لرؤية تعديلات المصدر قبل إعادة بناء الحزمة.
راجع README.md للأوامر والاختبارات.
