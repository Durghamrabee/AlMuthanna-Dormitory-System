# السجلات المستوردة الناقصة وبيانات الملف السابق

يسمح الاستيراد المعتمد بحفظ سجل الطالب الذي تنقصه معلومات غير موجودة في المصدر،
مثل الرقم الجامعي والهاتف وبيانات ولي الأمر والقضاء. تبقى هذه الحقول فارغة؛
لا تُولد أرقام جامعية أو هواتف أو أسماء افتراضية لتجاوز النقص.

تظهر السجلات في «إدارة الطلبة» مع عمود «حالة البيانات». افتح «تعديل» لمعرفة الحقول
المطلوب استكمالها. يبقى الحفظ العادي ملزماً بالحقول المطلوبة، ويمكن إكمال السجل
بالمعلومات الصحيحة ثم حفظه دون استبدال بيانات المصدر الأصلية.

يُفتح زر «عرض بيانات الملف السابق» من استمارة الطالب، أو «بيانات الملف السابق» من
تفاصيل الطالب المستورد. تعرض النافذة الملف والسنة الدراسية والقسم ورقم الصف والقيم
الأصلية والملاحظات للقراءة فقط. النصوص تُعرض كنص عادي؛ لا تُشغل تعليمات أو روابط
أو معادلات واردة داخل الملف.

الغرف والبنايات الموجودة في ملف السنة السابقة محفوظة للمراجعة، ولا تُنشئ تسكيناً
حالياً أو حركة نقل أو حجز غرفة تلقائياً. تُستكمل البيانات المطلوبة أولاً قبل تخصيص
سكن جديد بالطريقة المعتادة. مبالغ الغرامات الأصلية تبقى معلومات مصدر للمراجعة؛
لا تُحول إلى قيود مالية أو قرارات إدارية جديدة.

يُجرى الاستيراد بعد أخذ نسخة احتياطية، مع الاحتفاظ بالملف الأصلي دون تعديل.
الاستيراد المتكرر للملف نفسه لا يضاعف سجلاته. تطابق الاسم وحده لا يكفي لدمج طالبين؛
تُحفظ حالات الاشتباه للمراجعة دون الكتابة فوق ملف طالب موجود.

## تشغيل أداة الاستيراد من المصدر

تكون المعاينة هي الوضع الافتراضي؛ لا تختار الأداة قاعدة بديلة ولا تعدّل ملف Excel.
من مجلد `DormitoryManagement`:

```powershell
.\.venv\Scripts\python.exe tools\import_students.py 'C:\Data\students.xlsx' --academic-year 2025-2026
```

للتنفيذ، أغلق البرنامج وحدد مسار قاعدته الموجودة صراحةً. احفظ نسخة مستقلة من الملف
الأصلي واستعمل سنة المصدر، دون تحويل غرفه القديمة إلى سكن حالي:

```powershell
.\.venv\Scripts\python.exe tools\import_students.py 'C:\Data\students.xlsx' --academic-year 2025-2026 --database "$env:LOCALAPPDATA\AlMuthannaDormitoryNative\db.sqlite3" --apply
```

تحجز الأداة قفل التطبيق، وتتحقق من هوية القاعدة، وتنشئ نسخة احتياطية قبل الترقية
والإضافة. يمكن تمرير `--expected-sha256` لرفض ملف تغيّر بعد مراجعته، و`--summary`
لحفظ ملخص إحصائي دون أسماء أو هواتف. إذا اكتملت الإضافة وتعذر حفظ الملخص فقط، تُظهر
الأداة أن الاستيراد اكتمل مع تحذير منفصل؛ لا تقدمه كعملية فاشلة وتطلب تكرار البيانات.

تُحفظ المسميات المرجعية الجديدة الواردة صراحةً في الملف مع مصدرها وملاحظة للمراجعة؛
المسمى غير المطابق لمحافظة أو قضاء لا يُستبدل بقيمة مفترضة. تبقى القيم الأصلية كاملة
ضمن نافذة المصدر، حتى عند توحيد اختصار واضح لاسم كلية أو قسم موجود.

## بنايات وغرف أوراق الملف

عند اعتماد أن كل ورقة تمثل بناية، يحدد اسم مثل «قسم طالبات رقم 1» بناية رقم 1
للإناث، و«قسم طلاب رقم 1» بناية مستقلة رقم 1 للذكور. يكون رقم البناية فريداً داخل
نوعها، ورقم الغرفة فريداً داخل بنايتها. توحّد بادئة الغرفة والمسافات فقط؛ «غ13»
و«غ 13» هما الغرفة 13، مع الاحتفاظ بالأصفار البادئة إن كانت مكتوبة في المصدر.

لربط دفعة سبق استيراد طلبتها، عاين أولاً ثم نفذ باستخدام القاعدة الموجودة:

```powershell
.\.venv\Scripts\python.exe tools\import_students.py 'C:\Data\students.xlsx' --academic-year 2025-2026 --source-housing-only
.\.venv\Scripts\python.exe tools\import_students.py 'C:\Data\students.xlsx' --academic-year 2025-2026 --database "$env:LOCALAPPDATA\AlMuthannaDormitoryNative\db.sqlite3" --apply --source-housing-only
```

يأخذ الأمر نسخة احتياطية وقفل التطبيق قبل الترقية والربط. لا يعيد إضافة الطلبة،
ولا يعدّل بياناتهم أو تسكينهم أو قيم المصدر. يحتفظ المرفق الموجود بمعرّفه وسعته
وحالته؛ تنشأ البنايات الجديدة غير مفعّلة، والغرف الجديدة غير مفعّلة وبسعة فارغة
لأن عدد الأسماء في الملف لا يثبت السعة القصوى. إعادة الربط لا تضاعف المرافق.
تُرفض الأرقام الملتبسة أو الارتباطات المتعارضة دون استبدالها تلقائياً.

من «البنايات والغرف» اختر تبويب «الغرف» والبناية المطلوبة. يعرض «طلبة الملف السابق»
طلبة الغرفة والسنة والورقة والصف، بينما يعرض «الساكنون حالياً» التسكين الحالي فقط.
تظهر روابط البناية والغرفة أيضاً ضمن «بيانات الملف السابق» لكل طالب. يجب إدخال
السعة الصحيحة وتفعيل البناية والغرفة قبل تخصيص سكن حالي، مع استكمال بيانات الطالب.
