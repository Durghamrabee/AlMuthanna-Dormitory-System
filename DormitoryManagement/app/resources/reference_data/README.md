# البيانات المرجعية المحلية

`iraq_university.json` يحتوي على 19 محافظة، و150 قضاء ضمن تغطية جزئية موثقة، و17 كلية، و35 قسماً/مسمى تسجيل.
الأسماء والعلاقات مستمدة من مصادر حكومية وجامعية؛ التفاصيل والروابط والقيود في `docs/reference-sources.md`.

لا تمثل الحزمة قائمة مكتملة للتقسيمات الإدارية الحالية أو آخر الاستحداثات الجامعية. بيانات أقضية التعداد مرجعها 2024،
والأسماء التي لم تُحسم لم تُخمن. كليات البرنامج الواحد التي لم يُتحقق من مسمى قسم تسجيل الطالب فيها تبقى دون قسم افتراضي.

البرنامج يزرع المراجع في قاعدة محلية جديدة، وتُدار التعديلات اللاحقة من الإعدادات حفاظاً على علاقات الطلبة.
لا يلزم الإنترنت أثناء التشغيل. لا يحتوي هذا المجلد على بيانات طلبة أو أشخاص حقيقيين.
