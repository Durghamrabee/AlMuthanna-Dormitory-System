# نظام إدارة طلبة الأقسام الداخلية — جامعة المثنى

**تطبيق مكتبي على Windows | Python · PySide6 · SQLAlchemy · SQLite**

نظام محلي باللغة العربية مع واجهة **RTL** لإدارة سجلات طلبة الأقسام الداخلية، والتسكين حسب البناية والغرفة والسعة، والبحث والتصفية، والتقارير بصيغتَي Excel وPDF، والمستمسكات، والنسخ الاحتياطية والاستعادة.

> **نطاق المستودع:** ملفات المصدر والأدلة والاختبارات. لا يتضمن مستندات الطلبة الفعلية أو قواعد بيانات التشغيل أو نسخها الاحتياطية أو حزم EXE الجاهزة.

## تشغيل البرنامج من المصدر

على Windows، ثبّت **Python 3.12 أو 3.13 (x64)**، ثم افتح PowerShell داخل مجلد `DormitoryManagement` ونفّذ:

```powershell
py -3.13 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe main.py
```

يمكن استخدام `py -3.12` إذا كان Python 3.12 هو المثبت.

بعد تجهيز البيئة يمكن تشغيل `start-native.cmd` من المجلد الرئيسي. إذا وُجدت حزمة تنفيذية مبنية محلياً فسيشغّلها المشغّل؛ وإلا سيستخدم البيئة المحلية `.venv`. راجع [دليل التطبيق المكتبي](DormitoryManagement/README.md) لتفاصيل التشغيل والبناء والاختبارات.

## بنية المشروع

| المسار في المستودع | المحتوى |
| --- | --- |
| `DormitoryManagement/` | كود التطبيق المكتبي، الواجهات والخدمات والاختبارات |
| `DormitoryManagement/docs/` | تعليمات التشغيل والتطوير وميزات التطبيق |
| `docs/` | توثيق هيكل المشروع وإجراءات التطوير |
| `legacy/django/` | مصدر نسخة Django/MySQL السابقة ووثائقها |
| `start-native.cmd` | مشغّل النسخة المكتبية بعد تجهيز بيئة التشغيل |
| `start-local.cmd` | مشغّل النسخة القديمة، بمتطلبات مستقلة |

**لا تُرفع إلى المستودع:** مجلدات التطوير المحلية مثل `.venv/` و`.tools/`، ومخرجات `dist/` و`releases/`، والأرشيفات والنسخ الاحتياطية، وقواعد البيانات المحلية والمستمسكات الخاصة. بعض هذه المجلدات قد توجد على جهاز التطوير فقط ولا تظهر في GitHub.
