# نظام إدارة طلبة الأقسام الداخلية — جامعة المثنى

برنامج مكتبي عربي يعمل محليًا على Windows. **للتشغيل افتح `start-native.cmd`.**
يحفظ بيانات الطلبة خارج مجلد البرنامج، وتبقى محفوظة عند تحديث ملفات التشغيل.

نسخة GitHub تضم المصدر والأدلة والاختبارات فقط. تُستبعد قواعد البيانات ومستمسكات
الطلبة والنسخ الاحتياطية والإعدادات الخاصة، وكذلك بيئات التطوير وحزم EXE المولّدة.

## خريطة المشروع

| المسار | وظيفته |
| --- | --- |
| `start-native.cmd` | تشغيل البرنامج المكتبي الحالي |
| `DormitoryManagement/` | مصدر البرنامج الحالي وشاشاته وخدماته واختباراته |
| `DormitoryManagement/dist/AlMuthannaNative/` | نسخة EXE الجاهزة مع مكتباتها ومواردها |
| `DormitoryManagement/releases/` | حزمة الإصدار الحالي وحزمة سابقة للرجوع |
| `docs/` | شرح هيكل المشروع وطريقة تطويره وصيانته |
| `legacy/django/` | النسخة القديمة كاملة مع بياناتها وإعداداتها وأدلتها |
| `start-local.cmd` | تشغيل نسخة Django القديمة عند الحاجة |
| `archives/` | أدلة الاستيراد والمراجع التاريخية الخاصة |

## البيانات والملفات المهمة

قاعدة البرنامج الحالي ونسخه الاحتياطية في
`%LOCALAPPDATA%\AlMuthannaDormitoryNative\`، ولا تُنقل مع ملفات المصدر.
بيانات النسخة القديمة وإعداداتها محفوظة داخل `legacy/django/`.
لا تستخدم قاعدة إحدى النسختين لتشغيل الأخرى.

مجلدا `.venv/` و`.tools/` المخفيان يحتويان بيئات وأدوات تطوير؛ ليس كل ما فيهما
قابلًا للحذف. تعتمد بيئة النسخة المكتبية الموجودة على المفسر `.tools/python313/`.
ولا تنقل ملف EXE وحده بعيدًا عن مجلد `_internal` المصاحب له.
