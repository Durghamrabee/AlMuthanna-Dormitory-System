# نسخة Windows المستقلة — نظام الأقسام الداخلية

## التثبيت والتشغيل

1. فك ضغط حزمة AlMuthannaDormitory-Windows إلى مجلد عادي، لا تشغّلها من داخل ZIP.
2. أغلق نسخة سطح المكتب السابقة إذا كانت تعمل، ثم اضغط Install.cmd.
3. يُنسخ البرنامج إلى مجلد المستخدم المحلي Programs/AlMuthannaDormitory، ويُنشأ
   اختصار «أقسام جامعة المثنى» على سطح المكتب. لا يحتاج تثبيت Python أو VS Code
   أو MySQL ولا صلاحيات مدير Windows.
4. ستظهر نافذة تشغيل عربية وتُفتح الواجهة في المتصفح. أبقِ نافذة التشغيل مفتوحة.
   زر «إيقاف النظام وإغلاق» ينهي الخادم المحلي بعد انتهاء الأعمال الجارية.

قاعدة البيانات والمستندات والإعدادات والنسخ تُحفظ منفصلة في:
%LOCALAPPDATA%\AlMuthannaDormitory

تحديث البرنامج لا يستبدل هذا المجلد. يُنسخ كل إصدار إلى مجلد version مستقل داخل مجلد البرنامج؛
تبقى الإصدارات السابقة محفوظة ويتغير الاختصار بعد اكتمال النسخ. لا تثبّت البرنامج داخل مجلد البيانات.
الحزمة لا تتضمن أية قاعدة بيانات أو كلمات مرور أو مستندات من جهاز المطور.

النظام يبدأ على جهاز جديد بقاعدة فارغة ووضع محلي بدون حساب كما طلب المستخدم.
كل مستخدم لهذا الجهاز يستطيع الوصول للبيانات في هذا الوضع. يمكن إعادة الحسابات
من .env؛ المصادقة والأدوار محفوظة في التطبيق. لا توجد كلمة مرور افتراضية.

## نقل بيانات نسخة المشروع الحالية

لا تُنقل بيانات VS Code/المشروع إلى النسخة المستقلة تلقائياً:

1. من النسخة الحالية افتح «النسخ الاحتياطي»، أنشئ نسخة ZIP كاملة ونزّلها.
2. افتح النسخة المستقلة، ومن نافذة التشغيل اضغط «استعادة نسخة احتياطية موثوقة».
3. اختر ملف ZIP الذي أنشأته. راجع التأكيد؛ يوقف البرنامج الخادم، يتحقق من الملف،
   وينشئ نسخة أمان من قاعدة البيانات والمستندات الحالية قبل الاستعادة.
4. تُطبق الترحيلات المطلوبة ويُفحص المخطط، ثم يعود التشغيل. تحتفظ العملية بنسخة
   أمان وبمجلد المستندات السابق ولا تحذف البيانات القديمة.

لا تستعد ملفات مجهولة المصدر. في حال فشل الاستعادة تُعرض رسالة وتبقى نسخ الأمان
موجودة. زر «فتح مجلد البيانات والنسخ» يفتح موضع الحفظ محلياً.

## التشغيل دون إنترنت

الحزمة تتضمن Python والاعتماديات وBootstrap وChart.js وخط Cairo. التشغيل والنسخ
والاستيراد والتنبيهات لا تحتاج إنترنت. تنزيل PDF يحتاج Microsoft Edge المثبت محلياً؛
لا يتطلب GTK/Pango. يمكن استخدام الطباعة من المتصفح إذا لم يوجد Edge.

قد يطلب Windows تأكيد ناشر البرنامج لأنه ليس موقعاً بشهادة تجارية. لم تُغيّر
الحزمة إعدادات حماية Windows ولا تعطلها. اختبر الحزمة وفق سياسة جهازك؛ لا توجد
مطالبة بأن الشهادة أو موافقة الجامعة الرسمية متوفرة.

## للمطور: إعادة البناء

من بيئة Windows بنفس معمارية الحزمة:

python -m pip install -r requirements-build.txt
python scripts/build_windows.py

تظهر الحزمة في releases. hook-django المخصص يتجنب سلوك PyInstaller الافتراضي
الذي قد ينسخ db.* من المشروع. يفحص سكربت البناء المخرجات ويرفض تضمين .env أو
SQLite أو private_media/private_mail/backups. يجب اختبار ملف EXE المبني فعلياً،
وليس تشغيل Python المصدر فقط، قبل تسليم إصدار جديد.
